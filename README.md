# RAPI Sekolah

RAPI Sekolah merupakan web yang dikembangkan untuk membantu pengelolaan fasilitas sekolah, khususnya peminjaman ruangan dan pengaduan kerusakan fasilitas.

## Fitur
- Dashboard pengguna
- Manajemen data ruangan
- Peminjaman ruangan
- Pengaduan kerusakan fasilitas
- Penanganan pengaduan oleh PIC
- Kalender kegiatan sekolah
- Manajemen pengguna berdasarkan role

## Teknologi
- Laravel 13
- PHP 8.3
- MySQL
- HTML, CSS, JavaScript
